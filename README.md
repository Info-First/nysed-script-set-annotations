# **Micro Focus Content Manager 10.0: TIFF Annotation Flattening & Rendition Automation**

## **1\. Overview & Technical Context**

### **The Challenge**

In Micro Focus Content Manager (CM) 10.0, annotations placed on TIFF images are stored non-destructively as separate vector overlay streams (managed via the integrated Objective Trapeze engine) rather than modifying the underlying raster image bytes.

* **Raw Extraction (ExtractDocument):** Extracts the pure TIFF byte stream directly from the CM document store. Standard external viewers lack the Trapeze vector rendering engine, causing annotations to be invisible.  
* **Document Rendering Service (DRS / Longevity):** Server-side DRS converts the raw byte stream using KeyView/PDF export filters. It does not invoke Trapeze to composite client vector annotations, resulting in unannotated PDFs.  
* **Desktop Client "Print Document":** When printing from the CM Desktop Client, the client invokes Trapeze to composite both the raster TIFF and vector overlay layers onto a Windows GDI Device Context (HDC). Printing to a virtual PDF printer captures this composited output, successfully "flattening" (burning in) the annotations into standard PDF pages.

### **The Solution Architecture**

1. **CM Desktop Client:** Batch-spools tagged TIFF records through the internal Trapeze engine.  
2. **clawPDF (Virtual Printer):** Silently intercepts the GDI print jobs, generates flattened PDFs, and names them using the record's unique Content Manager Record URI (\<URI\>.pdf).  
3. **PowerShell \+ TRIM.SDK:** Scans the output directory, instantiates each record directly by its URI, and attaches the flattened PDF back to CM as a **Longevity** rendition.

## **2\. Prerequisites**

* **Content Manager 10.0 Desktop Client** installed and logged into the target dataset.  
* **TRIM.SDK.dll** present on the host machine (typically located at C:\\Program Files\\Micro Focus\\Content Manager\\TRIM.SDK.dll).  
* **clawPDF** (Open-source virtual PDF printer):  
  * Download from GitHub (clawsoftware/clawPDF) or install via Windows Package Manager:  
    winget install clawsoftware.clawPDF

* **User Permissions:** The executing account must have permission to edit records and attach child renditions in CM.

## **3\. clawPDF Configuration**

Configure clawPDF once to enable fully silent, unattended PDF generation.

1. Open **clawPDF Settings**.  
2. Select **Profiles** (or edit \<Default Profile\>).  
3. Configure the following tabs:

### **A. Auto-Save Tab**

* Check **Enable automatic saving**.  
* **Target Folder / Template:** Set your output path and file naming token:  
  C:\\FlattenedPDFs\\\<DocName\>.pdf

  *(Ensure the token matches how your client outputs the URI, or use the appropriate document property token so the filename outputs as \<URI\>.pdf, e.g., 311.pdf).*  
* Ensure **Ensure unique filenames** is checked (prevents overwrites in case of conflicts).

### **B. Save / General Tab**

* Uncheck **Open with default viewer after conversion** (critical to prevent hundreds of PDF reader windows from spawning during batch jobs).  
* Set **Interactive Dialogs** to **Never / Silent**.

### **C. Actions Tab**

* Verify no post-processing interactive popups are configured.  
4. Click **Save**.  
5. *(Optional)* Set **clawPDF** as the Windows Default Printer during the batch operation to streamline the CM print dialogue.

## **4\. Batch Printing from Content Manager Desktop**

1. Open the **Content Manager Desktop Client**.  
2. Run your query to locate the target TIFF records:  
   extension:tif

3. Tag all records to be processed:  
   * Press **Ctrl \+ A** (or right-click \> **Tag All**).  
4. Right-click any highlighted record and select:  
   * **Electronic** \> **Print Document**  
5. In the standard Windows Print dialogue:  
   * Select **clawPDF** as the printer.  
   * Click **OK** (or press Enter).

**Note:** CM Desktop displays the print dialogue only **once** for the entire batch. The internal client engine will loop through each tagged record, render the TIFF and vector overlays via Trapeze, and queue each job to clawPDF.

## **5\. Attaching Renditions via PowerShell (TRIM.SDK)**

Once clawPDF finishes spooling the PDFs into your staging directory (e.g., C:\\FlattenedPDFs), execute the following script to attach the flattened PDFs back to the original records as official Longevity renditions.

Save as Attach-FlattenedRenditions.ps1:

\<\#  
.SYNOPSIS  
&nbsp;&nbsp;&nbsp;&nbsp;Attaches flattened PDFs generated by clawPDF back to Content Manager records as Longevity renditions.

.DESCRIPTION  
&nbsp;&nbsp;&nbsp;&nbsp;Scans a folder for PDF files named by Record URI (e.g., '311.pdf'), locates the record via TRIM.SDK,  
&nbsp;&nbsp;&nbsp;&nbsp;and updates or creates a Longevity rendition.  
\#\>

\[CmdletBinding()\]  
param (  
&nbsp;&nbsp;&nbsp;&nbsp;\[string\]$StagingFolder \= "C:\\FlattenedPDFs",  
&nbsp;&nbsp;&nbsp;&nbsp;\[string\]$TrimSdkPath   \= "C:\\Program Files\\Micro Focus\\Content Manager\\TRIM.SDK.dll",  
&nbsp;&nbsp;&nbsp;&nbsp;\[switch\]$ArchiveOnSuccess \= $true  
)

\# 1\. Load TRIM SDK  
if (-not (Test-Path $TrimSdkPath)) {  
&nbsp;&nbsp;&nbsp;&nbsp;Write-Error "TRIM.SDK.dll not found at '$TrimSdkPath'."  
&nbsp;&nbsp;&nbsp;&nbsp;return  
}  
Add-Type \-Path $TrimSdkPath

\# 2\. Connect to Database  
$db \= New-Object TRIM.SDK.Database  
try {  
&nbsp;&nbsp;&nbsp;&nbsp;$db.Connect()  
&nbsp;&nbsp;&nbsp;&nbsp;Write-Host "Connected to Content Manager Dataset: $($db.DatasetId)" \-ForegroundColor Cyan  
}  
catch {  
&nbsp;&nbsp;&nbsp;&nbsp;Write-Error "Failed to connect to Content Manager database: $\_"  
&nbsp;&nbsp;&nbsp;&nbsp;return  
}

\# 3\. Process PDF Files  
if (-not (Test-Path $StagingFolder)) {  
&nbsp;&nbsp;&nbsp;&nbsp;Write-Error "Staging directory '$StagingFolder' does not exist."  
&nbsp;&nbsp;&nbsp;&nbsp;return  
}

$pdfFiles \= Get-ChildItem \-Path $StagingFolder \-Filter "\*.pdf"  
if ($pdfFiles.Count \-eq 0\) {  
&nbsp;&nbsp;&nbsp;&nbsp;Write-Warning "No PDF files found in '$StagingFolder'."  
&nbsp;&nbsp;&nbsp;&nbsp;return  
}

$archiveDir \= Join-Path $StagingFolder "Attached\_Archive"  
if ($ArchiveOnSuccess \-and (-not (Test-Path $archiveDir))) {  
&nbsp;&nbsp;&nbsp;&nbsp;New-Item \-ItemType Directory \-Path $archiveDir | Out-Null  
}

$successCount \= 0  
$failCount \= 0

foreach ($file in $pdfFiles) {  
&nbsp;&nbsp;&nbsp;&nbsp;$uriString \= \[System.IO.Path\]::GetFileNameWithoutExtension($file.Name)

&nbsp;&nbsp;&nbsp;&nbsp;\# Validate that filename is a valid numeric URI  
&nbsp;&nbsp;&nbsp;&nbsp;$uri \= 0  
&nbsp;&nbsp;&nbsp;&nbsp;if (-not \[long\]::TryParse($uriString, \[ref\]$uri)) {  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Write-Warning "Skipping '$($file.Name)' \- filename is not a valid numeric Record URI."  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;continue  
&nbsp;&nbsp;&nbsp;&nbsp;}

&nbsp;&nbsp;&nbsp;&nbsp;try {  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;\# Directly instantiate the Record using its URI  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;$record \= New-Object TRIM.SDK.Record($db, $uri)

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;if (-not $record \-or \-not $record.IsElectronic) {  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Write-Warning "Record URI $uri not found or does not contain an electronic attachment."  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;$failCount++  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;continue  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;}

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;\# Check for existing Longevity rendition to prevent duplicate rendition conflicts  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;$existingRendition \= $null  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;foreach ($rend in $record.ChildRenditions) {  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;if ($rend.TypeOfRendition \-eq \[TRIM.SDK.RenditionType\]::Longevity) {  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;$existingRendition \= $rend  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;break  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;}  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;}

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;if ($existingRendition) {  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;$existingRendition.SetDocument($file.FullName)  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Write-Host "Updated existing Longevity rendition on Record $($record.Number) (URI: $uri)" \-ForegroundColor Yellow  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;} else {  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;$newRendition \= $record.ChildRenditions.NewRendition(\[TRIM.SDK.RenditionType\]::Longevity)  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;$newRendition.SetDocument($file.FullName)  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Write-Host "Created Longevity rendition on Record $($record.Number) (URI: $uri)" \-ForegroundColor Green  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;}

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;\# Commit changes to Content Manager  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;$record.Save()  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;$successCount++

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;\# Move to archive folder if requested  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;if ($ArchiveOnSuccess) {  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Move-Item \-Path $file.FullName \-Destination (Join-Path $archiveDir $file.Name) \-Force  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;}  
&nbsp;&nbsp;&nbsp;&nbsp;}  
&nbsp;&nbsp;&nbsp;&nbsp;catch {  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Write-Error "Failed processing URI $uri ($($file.Name)): $\_"  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;$failCount++  
&nbsp;&nbsp;&nbsp;&nbsp;}  
}

Write-Host "\`n----------------------------------------"  
Write-Host "Processing complete."  
Write-Host "Successfully attached: $successCount" \-ForegroundColor Green  
Write-Host "Failed:                $failCount" \-ForegroundColor $(if ($failCount \-gt 0\) { "Red" } else { "Gray" })  
Write-Host "----------------------------------------"

## **6\. Verification & Quality Assurance**

To verify that annotations are properly flattened and stored in Content Manager:

1. In the CM Desktop Client, locate one of the processed records.  
2. Select the record and check the lower preview pane:  
   * **Document Tab:** Displays the original, un-flattened TIFF.  
   * **Rendition Tab:** Displays the newly attached PDF.  
3. Open the **Rendition Tab** or double-click to view the PDF in an external viewer (Acrobat, Edge, etc.).  
4. Confirm all highlights, text boxes, stamps, and redactions are permanently burned into the PDF raster/vector content.
