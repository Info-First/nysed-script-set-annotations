# **Micro Focus Content Manager 10.0: TIFF Annotation Flattening & Rendition Automation**

## **1\. Overview & Technical Context**

### **The Challenge**

In Micro Focus Content Manager (CM) 10.0, annotations placed on TIFF images are stored non-destructively as separate vector overlay streams (managed via the integrated Objective Trapeze engine) rather than modifying the underlying raster image bytes.

* **Raw Extraction (ExtractDocument):** Extracts the pure TIFF byte stream directly from the CM document store. Standard external viewers lack the Trapeze vector rendering engine, causing annotations to be invisible.  
* **Document Rendering Service (DRS / Longevity):** Server-side DRS converts the raw byte stream using KeyView/PDF export filters. It does not invoke Trapeze to composite client vector annotations, resulting in unannotated PDFs.  
* **Desktop Client "Print Document":** When printing from the CM Desktop Client, the client invokes Trapeze to composite both the raster TIFF and vector overlay layers onto a Windows GDI Device Context (HDC). Printing to a virtual PDF printer captures this composited output, successfully "flattening" (burning in) the annotations into standard PDF pages.

### **The Solution Architecture**

1. **CM Desktop Client:** Batch-spools tagged TIFF records through the internal Trapeze engine.  
2. **clawPDF (Virtual Printer):** Silently intercepts the GDI print jobs, generates flattened PDFs, and names them using the record's unique Content Manager Record URI (\<URI\>.pdf).  
3. **PowerShell \+ TRIM.SDK:** Scans the output directory, instantiates each record directly by its URI, and attaches the flattened PDF back to CM as a **Longevity** rendition.

## **2\. Prerequisites**

* **Content Manager 10.0 Desktop Client** installed and logged into the target dataset.  
* **TRIM.SDK.dll** present on the host machine (typically located at C:\\Program Files\\Micro Focus\\Content Manager\\TRIM.SDK.dll).  
* **clawPDF** (Open-source virtual PDF printer):  
  * Download from GitHub (clawsoftware/clawPDF) or install via Windows Package Manager:  
    winget install clawsoftware.clawPDF

* **User Permissions:** The executing account must have permission to edit records and attach child renditions in CM.

## **3\. clawPDF Configuration**

Configure clawPDF once to enable fully silent, unattended PDF generation.

1. Open **clawPDF Settings**.  
2. Select **Profiles** (or edit \<Default Profile\>).  
3. Configure the following tabs:

### **A. Auto-Save Tab**

* Check **Enable automatic saving**.  
* **Target Folder / Template:** Set your output path and file naming token:  
  C:\\FlattenedPDFs\\\<DocName\>.pdf

  *(Ensure the token matches how your client outputs the URI, or use the appropriate document property token so the filename outputs as \<URI\>.pdf, e.g., 311.pdf).*  
* Ensure **Ensure unique filenames** is checked (prevents overwrites in case of conflicts).

### **B. Save / General Tab**

* Uncheck **Open with default viewer after conversion** (critical to prevent hundreds of PDF reader windows from spawning during batch jobs).  
* Set **Interactive Dialogs** to **Never / Silent**.

### **C. Actions Tab**

* Verify no post-processing interactive popups are configured.  
4. Click **Save**.  
5. *(Optional)* Set **clawPDF** as the Windows Default Printer during the batch operation to streamline the CM print dialogue.

## **4\. Batch Printing from Content Manager Desktop**

1. Open the **Content Manager Desktop Client**.  
2. Run your query to locate the target TIFF records:  
   extension:tif

3. Tag all records to be processed:  
   * Press **Ctrl \+ A** (or right-click \> **Tag All**).  
4. Right-click any highlighted record and select:  
   * **Electronic** \> **Print Document**  
5. In the standard Windows Print dialogue:  
   * Select **clawPDF** as the printer.  
   * Click **OK** (or press Enter).

**Note:** CM Desktop displays the print dialogue only **once** for the entire batch. The internal client engine will loop through each tagged record, render the TIFF and vector overlays via Trapeze, and queue each job to clawPDF.

## **5\. Attaching Renditions via PowerShell (TRIM.SDK)**

Once clawPDF finishes spooling the PDFs into your staging directory (e.g., C:\\FlattenedPDFs), execute the following script to attach the flattened PDFs back to the original records as official Longevity renditions.

Save the following script as `Attach-FlattenedRevisions.ps1` and run it from a PowerShell terminal:

```powershell
<#
.SYNOPSIS
    Checks in flattened PDFs generated by clawPDF as new Revisions on Content Manager records.

.DESCRIPTION
    Scans a folder for PDF files named by Record URI (e.g., '311.pdf'), loads the record via TRIM.SDK,
    and checks in the PDF as a new revision via Record.SetDocument(). The original TIFF is preserved
    in the record's revision history.
#>

[CmdletBinding()]
param (
    [Parameter(Mandatory = $false)]
    [string]$StagingFolder = "C:\FlattenedPDFs",

    [Parameter(Mandatory = $false)]
    [string]$TrimSdkPath   = "C:\Program Files\Micro Focus\Content Manager\TRIM.SDK.dll",

    [Parameter(Mandatory = $false)]
    [string]$RevisionComment = "Flattened PDF with burned-in annotations",

    [Parameter(Mandatory = $false)]
    [switch]$ArchiveOnSuccess = $true
)

# 1. Load TRIM SDK Assembly
if (-not (Test-Path -LiteralPath $TrimSdkPath)) {
    Write-Error "TRIM.SDK.dll not found at '$TrimSdkPath'."
    return
}
Add-Type -Path $TrimSdkPath

# 2. Establish Database Connection
$db = New-Object TRIM.SDK.Database
try {
    $db.Connect()
    Write-Host "Connected to Content Manager Dataset: $($db.DatasetId)" -ForegroundColor Cyan
}
catch {
    Write-Error "Failed to connect to Content Manager database: $_"
    return
}

# 3. Locate Staging Directory
if (-not (Test-Path -LiteralPath $StagingFolder)) {
    Write-Error "Staging directory '$StagingFolder' does not exist."
    return
}

$pdfFiles = Get-ChildItem -Path $StagingFolder -Filter "*.pdf"
if ($pdfFiles.Count -eq 0) {
    Write-Warning "No PDF files found in '$StagingFolder'."
    return
}

$archiveDir = Join-Path $StagingFolder "Attached_Archive"
if ($ArchiveOnSuccess -and (-not (Test-Path -LiteralPath $archiveDir))) {
    New-Item -ItemType Directory -Path $archiveDir | Out-Null
}

$successCount = 0
$failCount = 0
$skippedCount = 0

# 4. Iterate and Check In as Revision
foreach ($file in $pdfFiles) {
    $uriString = [System.IO.Path]::GetFileNameWithoutExtension($file.Name)

    # Validate that filename is a valid numeric URI
    $uri = 0
    if (-not [long]::TryParse($uriString, [ref]$uri)) {
        Write-Warning "Skipping '$($file.Name)' - filename is not a valid numeric Record URI."
        $skippedCount++
        continue
    }

    try {
        # Directly instantiate the Record using its URI
        $record = New-Object TRIM.SDK.Record($db, $uri)

        if (-not $record -or -not $record.IsElectronic) {
            Write-Warning "Record URI $uri not found or contains no electronic document."
            $failCount++
            continue
        }

        # Verify the record is not locked / checked out
        if ($record.IsCheckedOut) {
            Write-Warning "Record URI $uri ($($record.Number)) is currently checked out. Skipping."
            $failCount++
            continue
        }

        # Encapsulate the file into an InputDocument
        $inputDoc = New-Object TRIM.SDK.InputDocument
        $inputDoc.SetAsFile($file.FullName)

        # SetDocument signature:
        # SetDocument(InputDocument doc, bool makeNewRevision, bool keepBookedOut, string comments)
        $record.SetDocument($inputDoc, $true, $false, $RevisionComment)

        # Commit update to Content Manager
        $record.Save()
        $successCount++

        Write-Host "Checked in new revision (PDF) on Record $($record.Number) (URI: $uri)" -ForegroundColor Green

        # Archive local staging file
        if ($ArchiveOnSuccess) {
            Move-Item -LiteralPath $file.FullName -Destination (Join-Path $archiveDir $file.Name) -Force
        }
    }
    catch {
        Write-Error "Failed checking in revision for URI $uri ($($file.Name)): $_"
        $failCount++
    }
}

Write-Host "`n----------------------------------------"
Write-Host "Processing complete."
Write-Host "Successfully revised: $successCount" -ForegroundColor Green
Write-Host "Failed:               $failCount" -ForegroundColor $(if ($failCount -gt 0) { "Red" } else { "Gray" })
Write-Host "Skipped:              $skippedCount" -ForegroundColor $(if ($skippedCount -gt 0) { "Yellow" } else { "Gray" })
Write-Host "----------------------------------------"
```

## **6\. Verification & Quality Assurance**

To verify that annotations are properly flattened and stored in Content Manager:

1. In the CM Desktop Client, locate one of the processed records.  
2. Select the record and check the lower preview pane:  
   * **Document Tab:** Displays the original, un-flattened TIFF.  
   * **Rendition Tab:** Displays the newly attached PDF.  
3. Open the **Rendition Tab** or double-click to view the PDF in an external viewer (Acrobat, Edge, etc.).  
4. Confirm all highlights, text boxes, stamps, and redactions are permanently burned into the PDF raster/vector content.
